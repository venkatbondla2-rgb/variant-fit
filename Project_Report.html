VariantFit: Social Fitness Platform

Enterprise Architecture & Scaling Cost Analysis Report (10,000+ DAU)

Important Clarification regarding Workout Posts:
All "Workout Completed", "Personal Record", and "Streak" posts generated automatically in the feed are 100% native HTML/CSS. They do not generate images and they do not use Cloudinary. They cost exactly $0 in media storage and consume zero Cloudinary credits.

1. Project Overview & Architecture

VariantFit is a modern, full-stack social fitness platform designed to handle thousands of concurrent users. It features real-time messaging, AI-driven diet planning, robust workout tracking, and a dynamic video-driven Reels feed.

2. Technology Stack

  • Frontend Framework: Next.js (React) utilizing App Router for static generation and server-side rendering.
  • Language: TypeScript & JavaScript
  • Styling: Tailwind CSS
  • Backend & Real-time Database: Google Firebase (Firestore)
  • Authentication: Firebase Authentication
  • Media Storage & CDN: Cloudinary (Optimized image and video delivery)

3. Cloud Infrastructure Cost Estimation for 10,000+ DAU

Scaling a social application to 10,000+ Daily Active Users (DAU) requires moving from Free Tiers to professional/paid SLAs to accommodate high bandwidth and database read/writes.

Service Plan Required Expected Usage (10k DAU) Estimated Monthly Cost
Vercel Pro Plan ~1TB Bandwidth, high serverless invocations for API routes ~$20.00 / month (Base) + Bandwidth overages
Firebase (Firestore & Auth) Blaze Plan (Pay-as-you-go) ~5M Document Reads/day, ~500k Writes/day, 50GB storage ~$30.00 - $60.00 / month
Cloudinary (Images & Reels) Plus Plan ~225 Credits (225GB Storage / 225GB Bandwidth). High video streaming costs. ~$89.00 / month
Total Estimated Expenses Production Scale 10,000+ Daily Active Users ~$139.00 - $169.00 / month

Cost Optimization Strategies Implemented

  • Native UI Components: Workout cards and achievements are rendered via code (Tailwind CSS) instead of generating and uploading images, saving massive amounts of Cloudinary credits.
  • Image Compression: Custom client-side compression (Canvas API) reduces image sizes by up to 80% before they hit Cloudinary limits.
  • Firestore Snapshot Management: Real-time listeners are tightly scoped and paginated to prevent excessive document reads.

4. Key Features Implemented

  • Immersive Social Feed & Reels: TikTok-style vertical video scrolling with auto-play and double-tap to like.
  • Real-time Chat Engine: Direct messaging with live updates, friend requests, and clickable shared post links.
  • Comprehensive Fitness Tracking: Logging workout sets, reps, and calculating real-time calories burned.
  • Privacy & Security: Public/Private account toggling, friend-only visibility, and role-based access control.
